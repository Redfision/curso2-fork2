Cómo leer lo que ves

  • Sin cola, el botón se queda esperando mientras salen todos los correos, y la tarjeta aparece ya llena. Quien llamó a tu API esperó el envío entero.
  • Con cola, la respuesta sale al instante y la tarjeta se llena sola, mientras el worker de composer run dev manda los correos.
  • Una tarjeta "en la cola" que no avanza: revisa que esté corriendo composer run dev, que es donde vive el worker.
  • Una tarjeta "detenido": el trabajo falló. Míralo con php artisan queue:failed, arregla la causa y reintenta con php artisan queue:retry all. La tarjeta vuelve a avanzar sola.
  • Esta página vive en tu proyecto, en public/, igual que el probador. Por eso puede hablar con tu API sin permisos especiales.
