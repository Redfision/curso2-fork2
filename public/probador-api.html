Qué significa cada código

200Salió bien y te devuelve datos.
201Se creó el recurso. Es la respuesta correcta de un POST que da de alta.
204Salió bien y no hay nada que devolver. Es lo que responde un borrado.
302Redirección. En una API es señal de que olvidaste el encabezado Accept: application/json.
401No sé quién eres: falta el token o ya no sirve.
403Sé quién eres y no te toca. Aquí habla tu Policy.
404Esa dirección o ese registro no existe.
422Los datos no pasaron la validación. El cuerpo te dice qué campo falló.
500Tronó tu código. Mira la terminal donde corre el servidor.
